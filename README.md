# 👨‍💻 Personal Profile Card

A modern, responsive personal profile card built using HTML5 and CSS3. This project showcases personal information, skills, social media profiles, and contact details through a clean and professional user interface.

## 🌟 Features

* Professional profile photo
* Personal introduction and designation
* Technical skills section
* GitHub and LinkedIn social links
* Contact button with email functionality
* Modern gradient background
* Smooth hover animations
* Responsive design for mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries
* Font Awesome Icons

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/jai-kumar-yadav/Personal-Portfolio-Card.git
```

2. Open the project folder.

3. Open `index.html` in your browser or use VS Code Live Server.
